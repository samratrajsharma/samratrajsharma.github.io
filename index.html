Selected Work

Orchestraty

Flagship

Your agents, aware of each other.

When several coding agents work on one repository, one can change something another relies on — a function's arguments, a route — and the break only shows up at merge. Orchestraty watches what each session changes and tells the affected agent, in a short note, before it builds on the old form. Notes are filled in from git and the code, never from a model, and nothing leaves your machine.

orchestraty.com ↗

Publications

  1. ICAIN · SSRN Apr 2025 ↗

    Decoding Toxicity: Unveiling Hidden Molecular Patterns with Graph Neural Networks

    Problem
    Testing every new chemical for toxicity in a lab is slow and expensive.
    Approach
    Treat each molecule as a graph of atoms and bonds, and train graph convolutional networks to predict toxicity from its structure.
    Outcome
    Predictions that point to the substructures behind them, so a chemist can see why a molecule is flagged.
    doi 10.2139/ssrn.5222180
  2. IEEE Xplore Nov 2023 ↗

    Smart Glasses for Blind People Using Obstacle Detection

    Problem
    A white cane only finds what it touches, and says nothing about what an obstacle is.
    Approach
    Glasses with cameras and ultrasonic sensing run obstacle detection on an NVIDIA Jetson and say what is ahead.
    Outcome
    Real-time obstacle alerts, currency recognition and an on-device assistant in one wearable.
    ieeexplore.ieee.org/document/10303495
  3. COMSIA 2025 ↗

    Advanced Path-Planning Algorithms on NVIDIA Jetson TX2 for Assistive Technologies

    Problem
    A wearable has to plan safe routes using only the compute it carries.
    Approach
